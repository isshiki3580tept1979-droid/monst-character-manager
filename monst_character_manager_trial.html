適正データの取り込み（JSON）
攻略サイト等で確認した適正を、形式どおりのJSONで取り込みます。まず「内容を確認」で結果を見てから「取り込む」を押してください。形式に誤りがあれば何も変更しません。登録済みのキャラ・進化形態と完全一致した行だけを取り込み、未登録のキャラは作成しません。取り込んだ適正は、確認済み（VERIFIED）と指定した行以外は「未検証」として入ります。
形式
{"format":"monst-suitability-import-v1",
 "stageKey":"破界の星墓::パライソ",
 "source":"GAMEWITH",  // GAMEWITH / ALTEMA / OTHER_SITE(+ "site") / GAME_CLEAR_MONSTERS
 "sourceUrl":"https://…", "sourceUpdatedAt":"2026-09-28",
 "evaluationType":"GRADE",  // RANK=rank / GRADE=grade / CANDIDATE=どちらも無し
 "entries":[{"characterName":"…","formName":"…",
   "grade":"S","verificationStatus":"UNVERIFIED"}]}
旧TOP20データの取り込み
旧形式（ステージ・順位ごとのキャラ名と端末別の所持状況）は削除せず残したまま、選んだ順位だけ新形式（適正＋所持個体）へ取り込みます。進化形態と出典はご自身で選んでください（自動では推測しません）。
